The Inter-Blockchain Communication Protocol is a neutral, open source
interoperability standard for digital ledger communication. It allows ledgers to
exchange any type of information encoded in bytes. IBC connections are
peer-to-peer; ledgers that use IBC communicate via self-hosted infrastructure
without a third-party intermediary. IBC is offered under an open source license
and does not have any in-protocol fees or token usage.
