## Reporting a vulnerability

Report privately through the [ibc-go security policy](https://github.com/cosmos/ibc-go/security/policy), not as a public issue. Paid disclosures go through the [Cosmos bug bounty on Immunefi](https://immunefi.com/bug-bounty/cosmos/information/).
