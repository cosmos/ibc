IBC has been audited by multiple independent security firms and engineers. 

Reports are published in the following repositories:

- [cosmos/ibc-contracts/docs/audits](https://github.com/cosmos/ibc-contracts/tree/main/docs/audits) covers the Solidity and Solana implementations.
- [cosmos/ibc-go/docs/audits](https://github.com/cosmos/ibc-go/tree/main/docs/audits) covers the protocol and the Go implementation.


## Protocol

| Report | Auditor | Date |
| --- | --- | --- |
| [IBC v2 collaborative audit](https://github.com/cosmos/ibc-go/blob/main/docs/audits/IBC-v2/IBC-v2-April-2025-Collaborative-Audit-Report.pdf) | Sherlock | April 2025 |

Covers the IBC v2 protocol, which removes the channel and connection handshakes, narrows the application interface, and opens IBC to domains such as Ethereum while staying compatible with existing channels. Audited at `79218a53`, final commit `d316a8b6`.

The same report is published in both repositories, so you may also see it as `2025-04-03-sherlock.pdf` in `ibc-contracts`.

| [ICS-20 token transfer v2](https://github.com/cosmos/ibc-go/blob/main/docs/audits/20-token-transfer/Atredis%20Partners%20-%20Interchain%20ICS20%20v2%20New%20Features%20Assessment%20-%20Report%20v1.0.pdf) | Atredis Partners | September 2024 |

| [08-wasm light client review](https://github.com/cosmos/ibc-go/blob/main/docs/audits/08-wasm/Ethan%20Frey%20-%20Wasm%20Client%20Review.pdf) | Ethan Frey | — |

The GMP review covers the ICS-27 GMP module — keeper, message and query servers, packet relay, derived accounts — together with the attestation light client, at commit `9ffc7482`. The ICS-20 v2 review covers multi-denomination support, the memo field, forwarding middleware, and path unwinding. The channel upgrades review covers upgrade handshakes, timeouts, state machine verification, and cancellation.

The second 08-wasm entry is a technical review of the client's architecture rather than a firm's audit report.

| Report | Auditor | Date |
| --- | --- | --- |

## Reporting a vulnerability

Report privately through the security policy for the affected repository, not as a public issue:

- [ibc-go security policy](https://github.com/cosmos/ibc-go/security/policy)
- [ibc-contracts security policy](https://github.com/cosmos/ibc-contracts/security/policy)

Paid disclosures go through the [Bug bounty on Immunefi](https://immunefi.com/bug-bounty/cosmos/information/).
