# Code of Conduct

The IBC project follows the [LF Decentralized Trust Code of Conduct](https://www.lfdecentralizedtrust.org/code-of-conduct).

All participants in project spaces, including repositories, issues, pull requests, discussions, community calls, and chat, are expected to uphold it in all interactions.

It is the only code of conduct in this repository, and it covers the specifications and documentation as well as the code. [spec/08-code-of-conduct.md](spec/08-code-of-conduct.md), which the Community Specification contributor agreement names, defers to this file.

To report a concern, contact the project's Code of Conduct responders listed in [TSC_MEMBERS.md](TSC_MEMBERS.md), or escalate to LFDT per the process in the linked Code of Conduct.

Reports are handled confidentially.
