# Code of Conduct

The IBC project follows the LF Decentralized Trust Code of Conduct.

All participants in project spaces, including repositories, issues, pull requests, discussions, community calls, and chat, are expected to uphold it in all interactions.

To report a concern, contact the project's Code of Conduct responders listed in TSC_MEMBERS.md, or escalate to LFDT per the process in the linked Code of Conduct.

Reports are handled confidentially.
