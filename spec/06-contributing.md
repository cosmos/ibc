# Contributing

Contributions to the IBC specifications follow the repository's [CONTRIBUTING.md](../CONTRIBUTING.md), including its [Specifications](../CONTRIBUTING.md#specifications) section, and the standardisation stages in [PROCESS.md](PROCESS.md). This Working Group has no separate contribution policy: this file is the one the [Contributor License Agreement](00-contributor-license-agreement.md) names, and it defers to those documents.

- **Agreement.** By making a contribution you agree to the [Contributor License Agreement](00-contributor-license-agreement.md), which covers the [Community Specification License 1.0](01-community-specification-license-v1.md), the [governance policy](05-governance.md), this policy and the [Code of Conduct](08-code-of-conduct.md), which is the repository's [CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md).
- **Sign-off.** Every commit must be signed off with `git commit -s`, as set out in [CONTRIBUTING.md](../CONTRIBUTING.md#developer-certificate-of-origin-dco).
- **Licenses.** Specifications are contributed under the Community Specification License 1.0, and source code under Apache 2.0, as set out in [04-license.md](04-license.md) and [Copyright and license](../CONTRIBUTING.md#copyright-and-license).
- **Roles.** Maintainers and Editors are as defined in [05-governance.md](05-governance.md): both are the TSC members listed in [TSC_MEMBERS.md](../TSC_MEMBERS.md).
