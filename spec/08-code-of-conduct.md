# Code of Conduct

The IBC specifications follow the repository's [Code of Conduct](../CODE_OF_CONDUCT.md), which adopts the [LF Decentralized Trust Code of Conduct](https://www.lfdecentralizedtrust.org/code-of-conduct). This Working Group has no separate code of conduct: this file is the one the [Contributor License Agreement](00-contributor-license-agreement.md) names, and it defers to the repository's.

To report a concern, follow [CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md).
